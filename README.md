These code utilizes cv2 for image processing, numpy to handle the math, and tkinter(for Q11) to provide a native file-explorer window. This allows users to select images 
The matrix transformation in both questionsis handled by the apply_universal_transform function. This function analyzes the 4 corners of the image, calculates exactly where they will land, and automatically expands the canvas size so the whole image always fits perfectly.
The math is fully automated in the menu system. The universal function processes 2x2 math matrices. When an option like "Rotate" is selected, the script automatically translates the entered angle into the correct matrix (using sine and cosine). The same matrix-building occurs for Resize, Flip, and Shear.
The final display renders the finished image in an OpenCV window using the cv2.WINDOW_NORMAL setting. This ensures that even heavily stretched images won't overflow the monitor, allowing the window to be clicked, dragged, and resized like a standard desktop application.
